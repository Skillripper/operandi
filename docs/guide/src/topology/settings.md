# Topology Mode, Constrain to Background and Merge Instance

## Topology Mode

**Topology Mode** draws the active meshes over the background meshes,
see-through, in the active 3D view, so the new mesh you are building stays
visible on top of the model under it. Click it again to turn it off.

## Constrain to Background

**Constrain to Background** makes points you add or move stick to the
surface of the background meshes. The Topology tab's tool buttons turn it
on for you; this button turns it on or off for every tool.

## Merge Instance

With a mirrored instance in use (from **Instance Mirror**), **Merge
Instance** bakes the selected mesh's one instance back into it, placed where
the instance is, and removes the instance item. Use it to make a symmetric
mesh whole again when you've finished one half.
