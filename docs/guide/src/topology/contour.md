# Contour

**Contour** turns a slice through the background mesh into a curve loop:
drag a line across the background, and where a plane through that line
cuts the mesh becomes a closed curve in the active mesh.

## How to use

1. Keep the background mesh visible but not selected, and select the mesh
   to add to.
2. Click **Contour** on the **Topology** tool tab.
3. Drag across the background mesh in the view.
4. Press **Q** to drop the tool.

Use the curves as guides for [Patch](../modeling/patch.md) or the
[Topology Pen](../modeling/topology-pen.md).
