# Vertex tab

The **Vertex** tool tab holds the tools and commands that work on points.
Most need Vertices mode (key **1**) and a point selection.

| Tools | Commands |
|---|---|
| [Create](create.md), [Vertex Bevel](vertex-bevel.md), [Vertex Extrude](vertex-extrude.md), [Merge Tool and Weld](merge-join.md), [Tear](tear.md), [Vertex Slide](vertex-slide.md) | [New Vertex, Set Position, Align](place-points.md), [Make Polygon and the Split commands](make-split.md), [Merge, Join](merge-join.md), [Collapse and Remove](remove-collapse.md), [Index order and Show Vertices](index-order.md) |

In Vertex mode some keys do the point version of a tool: **B** is Vertex
Bevel, **Shift+X** is Vertex Extrude, **S** is Vertex Slide,
**Control+Backspace** collapses and **Shift+Backspace** removes.
