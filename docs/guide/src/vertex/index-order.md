# Index order and Show Vertices

Every point has a number, its index. These commands change the order, for scripts and exchange formats that care about it.

## The commands

| Button | What it does |
|---|---|
| **Reorder Index...** | **Swap** the two selected points' indices, or move the selection to the **Top** or **Bottom** of the list. |
| **Sync Index Order** | Renumbers the points in the order the polygons use them. |
| **Show Vertices** | Shows every point in this view in every mode. Off: the **Display** menu's **Show Vertices** setting decides. |
