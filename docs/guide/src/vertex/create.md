# Create

**Create** adds new points where you click.

## How to use

1. Click **Create** in the **Vertex Tools** section of the **Vertex** tool
   tab.
2. Click in the view: each click adds a point on the **Work Plane**.
3. Press **Q**, or click **Drop Tool**, to keep the result. **Cancel** takes it back.

To add one point at exact coordinates, use **New Vertex...** on
[Place points](place-points.md).
