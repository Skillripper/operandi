# Tear

**Tear** splits a corner off: the selected polygons' corner at a point gets its own point, which then moves by **Offset**, tearing the polygons apart there.

## How to use

1. Select polygons, then a point on them.
2. Click **Tear** on the **Vertex** tool tab.
3. Drag, or type **Offset**.
4. Press **Q**, or click **Drop Tool**, to keep the result. **Cancel** takes it back.
