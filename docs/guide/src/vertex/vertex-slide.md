# Vertex Slide

**Vertex Slide** moves points along one of their edges, so the shape of the mesh stays the same.

## How to use

1. Press **1** for Vertices and select the points.
2. Press **S**, or click **Vertex Slide**.
3. Drag in the view.
4. Press **Q**, or click **Drop Tool**, to keep the result. **Cancel** takes it back.

## Properties

| Name | What it does | Default |
|---|---|---|
| **Merge Vertices** | A point that reaches its neighbour merges with it. | Off |
| **Face Handle** | Kept as a setting; it doesn't change the slide yet. | Off |
