# Curve commands

One-click commands for building curves and polygons from them.

| Button | What it does |
|---|---|
| **Set Curves Color…** | The colour curves draw in this view. A view setting, not saved in the scene. |
| **Freeze...** | Freezes curves and subdivision surfaces into plain polygons, with the last [Freeze](../edit/freeze.md) settings. |
| **Align Winding** | Makes every selected closed curve run the same way round. |
| **Make Open Curve** | Makes an open curve through the selected points, in the order you selected them. |
| **Make Closed Curves** | Makes a closed curve through the selected points, in the order you selected them. |
| **Make Curve Fill** | Adds a flat polygon filling each selected closed curve; the curve stays. |
| **Edges to Curves** | Makes curves along the selected edges. |
