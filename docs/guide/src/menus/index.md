# Menus

Every command in Operandi is in a menu. On a Mac the menus are in the macOS menu bar at the top of the screen; on Windows and Linux they are in the menu bar at the top of the window. Each page lists one menu's entries in order, with the key that runs an entry (if it has one) and the command it runs, which you can also type in the **Command entry** or use in scripts.

Menus are forms: **Edit Forms** in Layout mode changes them, so yours may differ.
