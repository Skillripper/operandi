# Edit tab

The **Edit** tool tab gathers tools that cut, rebuild and tidy up a mesh.

| Section | Tools |
|---|---|
| Edit Tools | [Slide](slide.md), the [Slice tools](slice-tools.md), [Dicer](dicer.md) |
| Center | [Center X, Y, Z and All](center.md) |
| Subdivide | [SDS Subdivide, Faceted, Smooth, Options and UnSubdivide](subdivide.md), [Freeze](freeze.md) |
| Booleans | [Boolean, Solid Drill, Axis Drill and Curve Boolean](booleans.md) |
| Retopology | [Topology Pen](../modeling/topology-pen.md), [Retopo Sketch, Automatic Retopology, Remesh](retopology.md) |
| Clean-up | [Fix Black Dots, Edge Zip, Diagonal Re-Direct](cleanup.md) |

Buttons whose name ends in "..." open a dialog first; the others act
straight away. Every one is a single undo step.
