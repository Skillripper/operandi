# Slide

**Slide** moves points or edges along the edges next to them, so the shape stays the same while the polygons shift.

## How to use

1. Press **2** for Edges (Edge Slide) or **1** for Vertices (Vertex Slide),
   and select what to slide.
2. Click **Slide** in the **Edit Tools** section of the **Edit** tool tab.
3. Drag in the view to slide.
4. Press **Q** to drop the tool.

Slide works in Vertex and Edge modes; in Polygon and Item mode it is greyed
(a polygon slide isn't available yet).
