# Edge Weight

**Edge Weight** sets how sharp the selected edges stay when the mesh is shown as a subdivision surface.

## How to use

1. Press **2** for Edges and select the edges.
2. Click **Edge Weight**.
3. Drag in the view, or type the weight: higher keeps the edge sharper.
4. Press **Q**, or click **Drop Tool**, to keep the result. **Cancel** takes it back.
