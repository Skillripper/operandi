# Edge commands

One-click commands on the selected edges.

## The commands

| Button | Key | What it does |
|---|---|---|
| **Spin** | **V** | Turns each selected edge to the next corners of its two polygons. |
| **Join** |  | Joins each selected edge into one point, at its end. |
| **Join Averaged** |  | Joins each selected edge into one point, at its middle. |
| **Collapse** | **Control+Backspace** | Removes the edges and joins their polygons. |
| **Remove** | **Shift+Backspace** | Removes the edges, merging the polygons either side into one. |
| **Edges To Curves** |  | Makes curves along the selected edges. |
| **Unbevel** |  | Turns a bevel's rows of edges back into a sharp edge. |
| **Edge Subdivide** | **D** | Adds points along the selected edges. |
