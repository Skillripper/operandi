# Split, Split Normals and Vertex Normal Tools

Commands that separate the mesh, or its shading, along edges.

## The commands

| Button | What it does |
|---|---|
| **Split** | Cuts the mesh apart along the selected edges, so each side gets its own points. |
| **Split Normals** | Makes the selected edges shade sharp without cutting the mesh. |
| **Vertex Normal Tools** | Opens the Vertex Normal Tools palette: hard edges and the vertex normal map. |
