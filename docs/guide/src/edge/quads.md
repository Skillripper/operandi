# Grow Quads and Fill Quads

Two commands that build four-sided polygons from edges.

## The commands

| Button | Key | What it does |
|---|---|---|
| **Grow Quads** | **Shift+Q** | Adds a row of quads along the selected border edges. |
| **Fill Quads** |  | Fills the hole bounded by the selected edges with a grid of quads. |
