# Edge Relax

**Edge Relax** evens out a bevel: it spreads the rows of a bevel's edges evenly round its curve.

## How to use

1. Select a bevel's edges, including the edge on either side.
2. Click **Edge Relax**.
3. Press **Q**, or click **Drop Tool**, to keep the result. **Cancel** takes it back.
