# Edge tab

The **Edge** tool tab holds the tools and commands that work on edges. Most
need Edges mode (key **2**) and an edge selection.

| Tools | Commands |
|---|---|
| [Edge Bevel and Edge Chamfer](edge-bevel.md), [Edge Extrude](edge-extrude.md), [Extend](extend.md), [Bridge](../duplicate/bridge.md), [Slide](../edit/slide.md), [Edge Relax](edge-relax.md), [Add Loop and Add Point](add-loop.md), [Edge Weight](edge-weight.md) | [Grow Quads and Fill Quads](quads.md), [Set Position](../vertex/place-points.md), [Split, Split Normals, Vertex Normal Tools](split.md), [Spin, Join, Collapse, Remove](edge-commands.md), [Edges To Curves, Unbevel, Edge Subdivide](edge-commands.md) |

In Edges mode some keys do the edge version of a tool: **B** is Edge Bevel,
**Shift+X** is Edge Extrude, **S** is Edge Slide, **D** is Edge Subdivide,
**Control+Backspace** collapses and **Shift+Backspace** removes.
