# Merge and Unmerge

**Merge** joins several mesh items into one. **Unmerge** splits one mesh item into one item per separate piece.

## How to use

**Merge**

1. In the **Items list**, click the mesh to merge into, then **Control**-click
   (or **Cmd**-click on a Mac) the others.
2. Click **Merge** in the **Merge** section of the **Create** tool tab.
   The others join the first one you selected.

**Unmerge**

1. Select a mesh made of separate pieces.
2. Click **Unmerge**. Each piece that isn't connected to the others
   becomes its own mesh item.

Both are one step each: **Ctrl+Z** takes them back.
