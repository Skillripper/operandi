# Snaps and Precision

**Snaps and Precision** opens a small panel of ready-made setups for exact work: tools with snapping already on, and the windows for exact sizes.

## How to use

1. Click **Snaps and Precision** in the **Measure** section of the **Create**
   tool tab. The **Snaps** panel opens; click the button again to close it.
2. Click a preset. It starts its tool with snapping set up.

## Presets

| Preset | What it does |
|---|---|
| **Drag Snap** | Drag any point, edge or polygon onto another to snap it there. |
| **Drag Snap Rigid** | The same, and everything connected moves with it. |
| **Planar Rotate Snap** | Rotate round one axis, snapping to a start and an end point. |
| **Planar Rotate Snap Axis** | Rotate round an axis set by snapped points, then snap to a start and an end point. |
| **Scale Absolute** | Scale by snapping to a start and an end point. |
| **Size Absolute** | Scale by snapping to a start point and typing a size. |

The panel also has **Advanced Handles**, which shows tools' extra handles
(the same as **Tool Handles: Advanced** in Preferences), and **Absolute
Scaling**, which opens the window for scaling to an exact size.
