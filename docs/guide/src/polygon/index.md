# Polygon tab

The **Polygon** tool tab holds the tools and commands that work on
polygons. Most need Polygons mode (key **3**) and a polygon selection; with
nothing selected, most work on the whole mesh.

| Tools | Commands |
|---|---|
| [Pen](../modeling/pen.md), [Bevel](../modeling/polygon-bevel.md), [Twist Bevel](twist-bevel.md), [Extrude](extrude.md), [Smooth Shift and Thicken](smooth-shift.md), [Chamfer Edit, Poly Haul, Sketch Extrude](more-tools.md), [Spike](spike.md), [Bridge](../duplicate/bridge.md), [Polygon Reduction](reduction.md) | [Make](../vertex/make-split.md), [Set Position](../vertex/place-points.md), [Triangles and quads](triangles.md), [Flip and Align](flip.md), [Merge, Remove, Collapse, Unify](merge-remove.md), [Scale Offset and Flatten](scale-offset.md), [Set Part and Set Material](part-material.md) |
