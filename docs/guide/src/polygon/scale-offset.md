# Scale Offset, Flatten and Split

Commands that inset, flatten or cut polygons.

## The commands

| Button | Key | What it does |
|---|---|---|
| **Scale Offset...** |  | Shrinks the selected polygons in their own planes by an inset distance. |
| **Scale Offset (Detach)...** |  | The same, onto new, unconnected points. |
| **Flatten Ngons** |  | Flattens polygons with more than four sides that aren't flat, across the whole mesh. |
| **Split** | **Control+L** | Connects selected opposite corners of a quad with a new edge. |
