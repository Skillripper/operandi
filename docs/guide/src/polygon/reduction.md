# Polygon Reduction

**Polygon Reduction** reduces the selected polygons toward a target count while keeping their shape.

## How to use

1. Press **3** for Polygons and select the polygons.
2. Click **Polygon Reduction**: it arms.
3. Click in the view to start, then set **Number**, or drag: left lowers
   **Number**, right raises it, up to the polygons you started with.
4. Click in the view (or **Apply**) to keep this reduction and reduce
   again from the result, or click **Drop** to keep it and turn the tool
   off.
