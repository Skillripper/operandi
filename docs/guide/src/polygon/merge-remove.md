# Merge, Remove and Collapse

Commands that join polygons, or take them away.

## The commands

| Button | Key | What it does |
|---|---|---|
| **Merge** |  | Joins the selected neighbouring flat polygons into one. |
| **Remove** | **Shift+Backspace** | Deletes the selected polygons, keeping all their points. |
| **Collapse** | **Control+Backspace** | Replaces each selected polygon with one point at the middle of its corners. |
| **Collapse Selection** |  | Replaces the selected polygons with triangles round one new point at the middle of their outline. |
| **Unify...** |  | Removes duplicate polygons. |

**Delete** removes polygons and points that nothing else uses.
