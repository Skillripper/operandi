# Flip and Align

Commands that turn polygons to face the other way, or the same way.

## The commands

| Button | Key | What it does |
|---|---|---|
| **Flip** | **F** | Reverses the selected polygons, so they face the other way. |
| **Flip It...** |  | Mirrors the selected polygons across an axis through the selection's centre, facing out. |
| **Flip It Origin...** |  | The same, across an axis through the world origin. |
| **Align** |  | Turns two selected neighbouring polygons to face the same way. |
