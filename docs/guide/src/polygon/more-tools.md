# Chamfer Edit, Poly Haul and Sketch Extrude

Three more interactive polygon tools.

## The tools

| Tool | Key | What it does |
|---|---|---|
| **Chamfer Edit** |  | Edits an existing chamfer or bevel: its width and rounding. |
| **Poly Haul** |  | Drag a polygon to pull it out and stretch its neighbours with it. |
| **Sketch Extrude** | **Alt+B** | Draw a stroke in the view; the selected polygons extrude along it. |
