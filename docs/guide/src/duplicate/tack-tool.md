# Tack Tool

**Tack Tool** puts the selection on a polygon you click, sitting on its surface.

## How to use

1. Select what you want to place.
2. Click **Tack Tool** on the **Duplicate** tool tab.
3. Click a polygon: the selection moves onto it.
4. Click **Tack Tool** again, or press **Q**, to stop.
