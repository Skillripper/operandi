# Duplicate and Duplicate Hierarchy

**Duplicate** copies the selected item in place; **Duplicate Hierarchy** copies each selected item with all its children.

## How to use

1. Select items in the **Items list** or the view.
2. Click **Duplicate** or **Duplicate Hierarchy** on the **Duplicate** tool
   tab.

**Duplicate** names the copy *Name (2)* and selects it; the item's children
stay with the original. **Duplicate Hierarchy** copies every child too and
keeps the links between them; the copies are selected.
